# Portal IBERO PGA (gestión para acreditaciones)
> Aplicación web autenticada para captura del currículum docente
> orientado a procesos de acreditación institucional.

## Uso
- El acceso público se limita a la pantalla de inicio de sesión.
- El resto de rutas requieren autenticación institucional.
- No indexar ni almacenar datos personales de docentes.
